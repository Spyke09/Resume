## Ключевые проекты

1. **АК «Россия»**. Разработка решения для формирования расписания автобусов на перроне при обслуживании рейсов: сбор и формализация ключевых требований и метрик качества совместно с бизнесом, построение и реализация нескольких моделей, интеграция решения в систему.

2. **АК «Россия»**. Aудит оптимизационной модели назначения ВС на рейсы: формализация математической постановки, аналитический разбор, выявление системных и локальных ошибок модели. Разработка совместно с бизнесом подхода многокритериальной оптимизации, который повысил удовлетворённость заказчика.

3. **ПАО «НЛМК»**. Разработка математической эвристики для планирования производства: MIP-модель с методом генерации столбцов, управляющим алгоритмом и иерархией критериев оптимизации. Новый подход заменил предыдущую модель, продемонстрировав лучшие результаты по метрикам качества (в среднем на 15% по главному критерию).

4. **Лаборатория МОИИ**. Разработка специализированного оптимизатора для переназначения воздушных судов: метод ветвей и границ с набором умных эвристик. Разработанный оптимизатор обошел CPLEX MIP.

5. **Huawei**. Участие в проекте по созданию Circuit-SAT солвера: разработка ядра и эвристик (как известных из литературы, так и собственных), интеграция их в модульный фреймворк.
